# MeetingAI UI 设计系统 v2.0

## 设计理念

**现代简约、专业高效、视觉层次清晰**

采用现代扁平化设计，结合微妙的阴影和圆角，营造专业而友好的用户体验。

## 1. 颜色系统

### 主色调
- **主色**: `#2563EB` (蓝色) - 代表专业、信任、科技感
- **主色浅**: `#3B82F6` - 悬停状态
- **主色深**: `#1D4ED8` - 按下状态
- **主色超浅**: `#EFF6FF` - 背景高亮

### 辅助色
- **成功色**: `#10B981` (绿色) - 成功状态、录音中
- **警告色**: `#F59E0B` (橙色) - 警告状态
- **错误色**: `#EF4444` (红色) - 错误状态、录音按钮
- **信息色**: `#6366F1` (紫色) - AI 相关功能

### 中性色
- **背景主色**: `#FFFFFF` (白色)
- **背景次色**: `#F8FAFC` (浅灰蓝)
- **背景三级**: `#F1F5F9` (更浅灰蓝)
- **背景四级**: `#E2E8F0` (边框色)

### 文字色
- **文字主色**: `#0F172A` (深灰黑)
- **文字次色**: `#475569` (中灰)
- **文字三级**: `#94A3B8` (浅灰)
- **文字禁用**: `#CBD5E1` (最浅灰)

### 特殊色
- **玻璃效果**: `rgba(255, 255, 255, 0.8)` - 毛玻璃背景
- **阴影色**: `rgba(0, 0, 0, 0.1)` - 卡片阴影
- **渐变主色**: `linear-gradient(135deg, #2563EB, #7C3AED)` - 渐变按钮

- **标准**: `cubic-bezier(0.4, 0, 0.2, 1)`

## 实施指南

### 1. 颜色使用
- 使用语义化颜色变量，不直接使用十六进制值
- 确保颜色对比度符合无障碍标准
- 在深色模式下提供相应的颜色方案

### 2. 字体使用
- 使用字体层级系统，保持一致性
- 正文使用 14px，标题使用相应的层级
- 确保中文字体渲染清晰

### 3. 间距使用
- 使用 4px 网格系统
- 保持组件间距一致
- 使用语义化间距变量

### 4. 组件使用
- 使用统一的组件样式
- 保持组件状态一致性
- 提供完整的交互反馈

### 5. 动画使用
- 使用统一的过渡时间
- 保持动画流畅自然
- 避免过度动画
